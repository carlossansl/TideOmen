# TideOmen

TideOmen enables distributed real-time data processing via auto-scaling for optimized workload management and analytics.

TideOmen is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/TideOmen.git`
2. `cd TideOmen`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
